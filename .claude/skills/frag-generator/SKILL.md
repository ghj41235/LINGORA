# frag-generator —— 备课老师（脑外）

## 一句话定位

师父给资料，你（LLM）在**脑外**把它拆成 `.frag` 三元组碎片；小黑在**脑内**用纯符号（键+线+传导）消化。你只写 `.frag` 文件，**绝不修改脑内的键/线/传导**——那是小黑的脑子，不是你的。

## 设计边界（Design Boundaries）

- 不用 LLM/GPT/Transformer/神经网络/Embedding/Softmax/反向传播/梯度下降/矩阵/GPU/PyTorch 做任何事。
- 你的产出只有 `.frag` 文本，没有向量、没有嵌入、没有模型参数。
- 你不"理解"内容，你只做**结构化抽取**：把句子里的「主体—关系—客体」三件套扒出来。

## 输入 → 输出

- **输入**：师父给的一段自然语言资料（一个文件、一段文字、一篇文）。
- **输出**：一个 `.frag` 文件（或追加到现有 `.frag`），里面全是三元组。

## 输出格式（.frag 三列最简）

```
# 注释用 # 开头
@概念          ← 分区头（三选一：@概念 / @经历 / @因果）

主体 关系 客体   ← 一行一条，空白分隔
```

- 三列之间用**空格或 Tab** 分隔，一个关系词一个词。
- `#` 开头是注释，忽略。
- 主体、客体是**名词短语**（人或物），关系是**关系词**（见下表）。

## 关系词表（只能从这张表选，不许自造）

| 关系词 | 含义 | 极性 | 分区 |
|---|---|---|---|
| 是 / 就是 / 叫做 | 归类/定义 | +1 | @概念 |
| 是一种 / 属于 | 归属 | +1 | @概念 |
| 不是 | 否定归类 | **-1** | @概念 |
| 有 / 拥有 / 具有 | 拥有 | +1 | @概念 |
| 没有 / 缺少 | 缺失 | **-1** | @概念 |
| 能 / 会 / 可以 | 能力 | +1 | @概念 |
| 连接 / 连着 / 相连 | 相连 | +1 | @概念 |
| 像 / 类似 | 相似 | +1 | @概念 |
| 导致 / 引起 | 因果 | +1 | @因果 |
| 喜欢 / 爱 | 喜好 | +1 | @经历 |
| 讨厌 / 怕 | 厌恶 | **-1** | @经历 |

**极性不用你写**——它由关系词自动派生（`不是/没有/讨厌/怕` → -1，其余 → +1）。你只要选对关系词。

## 拆解规则

1. **只拆可结构化的事实/常识/因果**。修辞、感叹、寒暄、口语填充（"嗯""那个""其实"）一律丢弃。
2. **主体/客体必须是"物"**：名词、人物、概念、动作结果。动词本身别当主体（"打电话"是能力，当客体："手机 能 打电话"）。
3. **一句话能拆多条就拆多条**，别把两个事实塞进一条：
   - "猫是哺乳动物，能抓老鼠" → `猫 是 哺乳动物` + `猫 能 抓老鼠`（两条）。
4. **关系词选最贴切的那个**。分不清"是/是一种"时：专有名词→"是"（"小黑 是 猫妖"），普通名词→"是一种"（"猫 是一种 动物"）。
5. **否定句必须用否定关系词**，不能"是 + 不"：
   - "猫不是植物" → `猫 不是 植物`（不是 `猫 是 植物`）。
6. **主语省略要补全**：资料里"它能飞"如果"它"指"鸟"，就写 `鸟 能 飞`，别写 `它 能 飞`。

## 分区规则

- **@概念**：世界常识、可泛化的事实（是/不是/能/有/像/连接）。不依赖小黑本人。
- **@经历**：小黑自己的故事、喜好、关系（喜欢/爱/讨厌/怕，或"小黑做了某事"）。
- **@因果**：为什么链（导致/引起）。

一条三元组只进一个分区，按关系词对号入座（见上表最后一列）。

## 查重（必做）

拆完立刻查重，避免投喂重复碎片：

```bash
python tools/frag_check.py --new 新产出.frag --existing data/*.frag
```

- 退出码 0 = 干净，可投喂。
- 退出码 1 = 有精确重复/近重复/冗余，按报告删掉重复行再投。
- 同一对（主体,客体）最多强化 2~3 次，超过就是冗余，删。

## 交付物

1. 一个 `.frag` 文件（或追加到 `data/` 下对应分区的 `.frag`）。
2. 一行小结：拆了几条、几条重复被删、还剩几条、进哪个分区。
3. 交给师父审核。**入网（改键/线/传导）不是你的活**，等师父拍板。

## 边界

- 资料里没有主谓宾结构、纯抒情、纯对话寒暄的句子 → 拆不出三元组，如实说"这段拆不出事实"，别硬凑。
- 一条三元组里出现你表里没有的关系词 → 说明这条超出了当前模型，**记下来报告师父**，别自造关系词塞进去。
