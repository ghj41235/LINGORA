# 罗小黑 · 键盘模型 AI

> 一只没有神经网络的猫。它的「思考」，是电流沿着电线扩散。

**v1.0 · 第三代**

罗小黑是一只住在师父家的小黑猫妖。这个仓库是它的「脑」——一套**纯符号**的认知模型。

不训练、不调参、不反向传播、没有权重文件。「思考」不是矩阵乘法，而是一个物理隐喻：
激活（电）在**键**与**键**之间的**电线**上传导、逐跳衰减、Hebbian 增强、缓慢遗忘。

---

## 一句话原理

```
键(Key)  →  线(Wire)  →  传导(Conduction)  →  花盆(Pot)  →  花园(Garden)  →  语法盆(Grammar)
记忆原子    关系边       推力扩散的「思考」     软隔离容器     多盆+跨盆桥接      格局→OUTPUT→句子
```

- **键**：记忆的最小原子，带亮度（0 / 1 / 2）、证据量、预测状态。
- **线**：键与键之间的关系边，有粗细、关系类型、极性（三态 -1 / 0 / +1）。
- **传导**：一次思考 = 从几个种子键出发，推力沿电线扩散、逐跳衰减、重新播种。
- **花盆**：把噪音隔开的软容器；**花园**：多个花盆 + 跨盆桥接，联想能跨主题走。
- **语法盆**：把激活格局映射到 OUTPUT 键，再落到句子模板，最后说出口。

---

## 为什么不是大模型

这是一个刻意**反向**的选择：主流 AI 用「参数化的语言模型 + 反向传播」逼近智能，
这里用「符号 + 图论 + 逻辑」直接搭一套最小可解释的认知系统。

因此仓库里有一条**不可修改的宪法**（完整清单见 `src/core/__init__.py`）：

> 禁止 LLM / Transformer / 神经网络 / Embedding / Softmax / 反向传播 / 梯度下降 /
> 矩阵乘法 / GPU / PyTorch / Diffusion / 强化学习 / 微调 / BPE 分词 / 模型权重文件……

唯一的「学习」机制是符号化的：**传导、Hebbian 增强、电线衰减、NARS 证据量、
HTM 时序、CBR 案例、语法键网络、产生式系统**——全部是图论 / 逻辑运算，不含微分与矩阵。

## 三代演进

| 代 | 形态 | 关键词 |
|---|---|---|
| 第一代 | 键盘模型 | 键 + 线 + 传导，最原始的扩散 |
| 第二代 | 花盆模型（v0.3） | Garden 多盆 + 跨盆桥接，隔离噪音 |
| **第三代** | **v1.0** | 六条路线并轨，认知子系统齐 |

## v1.0 六条路线

| 路线 | 模块 | 一句话 |
|---|---|---|
| CD 概念原语 | `primitives.py` | 29 个原语 + 17 种生活句式拆解 |
| NARS 证据量 | `evidence.py` `inference.py` | 频率 × 置信度 → 期望值；演绎/归纳/类比 |
| HTM 时序预测 | `temporal.py` | 预测状态机 0 → 1 → 2 |
| Copycat 温度 | `temperature.py` | 4 因子调控传导的「冷热」 |
| CBR 案例推理 | `case.py` | 签名匹配 + 快照预热，跳过传导 |
| 语法键网络 | `grammar.py` | 激活格局 → OUTPUT 键 → 句子模板 |

## 快速开始

```bash
# 唯一第三方依赖：jieba（中文分词）
pip install jieba

# 从项目根目录运行
python main.py

python -m src.runtime.main

## .frag 碎片知识

`.frag` 是给「脑外备课」用的结构化知识格式——三列最简三元组（`主体 关系 客体`），
跳过自然语言拆解，直接投喂成键和线：

```
@概念
手机 能 打电话
猫 是一种 动物
猫 不是 植物
```

备课查重用 `tools/frag_check.py`（纯 char bigram 去重，不碰向量）。生成器见 `.claude/skills/frag-generator/`。

```
