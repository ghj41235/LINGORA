# luoxiaohei（罗小黑）开发规范 · 外包任务共用

## 项目是什么
luoxiaohei 是一个**纯符号**的认知 AI，核心隐喻「键 + 电线 + 网络 + 传导」：
- 键（Key）：记忆原子（一个概念/事实），带亮度（0/1/2 三段）、NARS 证据量（频率 × 置信度）、预测状态。
- 电线（Wire）：键之间的关联，有粗细、关系类型、滑移距离。
- 网络（Network）：键 + 线的图。
- 传导（Conduction）：推力沿电线扩散、逐跳衰减（即"扩散激活"）。
- 花盆/花园（Pot/Garden）：主题空间，多盆 + 跨盆桥接。

代码：Python，中文注释，风格朴素、贴近现有代码。项目根目录 `src/` 下分 core（引擎）、runtime（主循环）、knowledge（文件柜）、inout（输入输出）、personality（性格）等。

## 铁律（绝对禁止 —— 最高优先级）
本项目**禁止一切神经网络相关技术**，任何形式、任何规模、任何包装都不行，包括：
LLM / 大语言模型、Transformer、神经网络、Embedding / 向量嵌入、余弦相似度、
Softmax / Sigmoid / ReLU、反向传播 / 梯度下降、损失函数 / 优化器、矩阵乘法、
GPU / CUDA、PyTorch / TensorFlow、tokenization、预训练 / 微调、概率采样。

**只允许**符号化 / 图论 / 逻辑运算：传导、Hebbian 增强、电线衰减、NARS 证据量、
HTM 时序状态机、CBR 案例推理、语法键网络、产生式系统。

> 你写的代码里**绝不能出现**上述被禁的词 / 概念 / 代码模式。
> 不要建议用 embedding、向量、神经网络、LLM、软标签之类的方法——那等于直接违规。
