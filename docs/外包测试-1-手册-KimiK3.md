## 任务：验证"不同输入 → 不同输出"

背景：系统一（对话输出）刚把语法匹配改成"传导驱动"，需要验证它真的做到"不同话题 → 不同回复"，而不是所有输入都卡在同一条（之前出过"无论输入什么都回小鱼干"的卡死 bug）。

### 你拿到的接口
- 运行：在项目根目录 `python -m src.runtime.main`。
- 交互式：先打印一段启动问候，然后打印提示 `师父> ` 等待一行输入；你输入一行后，它 `print` 出回复（可能多行，后面可能跟 `〔…〕` 的中括号元信息行，如 `〔已自动保存〕`、`〔想了 X 秒…〕`——这些**不是正文**）。
- 参数：`--file <路径>` 指定记忆文件；`--new` 全新开始。验证时**务必用临时文件**（如 `tmp_verify.luoxiaohei`），别碰真实的 `luoxiaohei.luoxiaohei`。

### 接口对应的源码片段（贴给你，免得猜）

主循环（`src/runtime/main.py` 的 `run()`）：

```python
while self.running:
    user_input = input("师父> ").strip()   # 打印 "师父> " 提示，然后读一行
    if not user_input:
        continue
    self._cool_residuals()
    self._process_input(user_input)        # 内部会 print 出回复
    self._background_tasks()
```

回复输出（`_handle_conversation` 尾部。**"正文"只有第一行 `print(response)`**，后面可能跟的 `〔…〕` 都是元信息、不是正文）：

```python
print(response)                 # ← 唯一一行"回复正文"

# 后面可能跟这些〔…〕元信息行（都要跳过）：
print(f"  〔小黑打了个哈欠——他真的很累了〕")      # 疲劳高时
print(f"  〔小黑揉了揉眼睛，有点累了〕")          # 疲劳中时
print(f"  〔小黑心想：'…' 要不要放进柜子里？…〕")  # 主动归档建议
print(f"  〔想了 {elapsed:.1f} 秒，…〕")          # 仅当思考 >5 秒
print(f"  〔已自动保存〕")                        # 保存时
print()                            # 每轮末尾一个空行
```

要点：**读输出直到下一个 `师父> ` 提示符**为止；正文 = 紧跟在你输入之后、且**不带 `〔` 前缀**的第一段文本。

### 你要交付的
写一个 `verify_speaking.py`（放项目根目录），用 `subprocess` 驱动：
1. 用 `python -m src.runtime.main --file tmp_verify.luoxiaohei --new` 起一个全新实例；
2. 依次喂入这几个话题差异大的句子（每句等它打印到下一个 `师父> ` 为止）：
   - 你好小黑
   - 小鱼干好吃吗
   - 你认识手机吗
   - 师父给你买了什么
   - 你喜欢吃什么
   - 讲一个笑话
3. 从每轮输出里抽出「回复正文」（去掉 `〔…〕` 元信息行和 `师父> ` 提示）；
4. 打印一张「输入 → 回复正文」对照表；
5. 报告：这 6 句的回复是否各不相同？如果有两句正文完全一样，明确标出来。

### 交付物
`verify_speaking.py` + 一份运行结果说明（哪几句输出相同 / 不同）。
